# 架空输电线路覆冰弧垂与舞动三维校核系统

面向 220kV 山区线路的网页版覆冰弧垂、交叉跨越净距与导线舞动校核工具。
TypeScript + three.js + Vite，线路台账与工况存 IndexedDB，无后端依赖。

## 启动

```bash
npm install
npm run dev        # 开发, 默认 http://127.0.0.1:5180
npm test           # 物理计算单元/集成测试 (node:test, 18 项)
npm run build      # 类型检查 + 生产构建
npm run preview    # 预览构建产物
```

首次打开自动生成演示线路：**石云山 220kV 线路，8 基塔、2 个耐张段（N1–N5、N5–N8），
含一处跨公路（第 2 档）、一处跨 10kV 线（第 6 档）、一处民房**。台账页可一键重置演示数据。

## 六个页面

| 页面 | 功能 |
| --- | --- |
| 线路台账 | 按耐张段管理档距/高差/悬垂串长/挂点坐标；TSV 杆塔明细表导入，档距高差不一致行自动标红（容差 0.5m） |
| 杆塔排位 | 猫头/酒杯/耐张三种程序化塔型，横担层与挂点可改；地形按中线+左右边线生成；公路/10kV/民房布置 |
| 导线工况 | 导线地线型号库（截面、单位重、E、α）；双/四分裂；7 种工况；状态方程解与老 Excel 抛物线表并排对照 |
| 三维校核 | 悬链线扫掠管、新月形/翼形渐变覆冰、间隔棒、悬垂串偏摆；实时净距标签，不满足标红；侧面/全线相机 |
| 舞动回放 | 三相+地线椭圆驻波轨迹（各相初相位差），逐帧相间距曲线、闪络打点、慢放/逐帧、沿线飞行、侧面锁定、次档距包络 |
| 校核报告 | 各工况弧垂表、净距不满足清单、舞动相间距曲线、三维截图，可打印 PDF 或导出 HTML |

## 计算模型（验收口径）

1. **精确悬链线**：`src/physics/catenary.ts`，水平张力 H 与线长 s 双向牛顿/二分求解，
   支持最低点落在档外的陡坡档。
2. **状态方程**：`src/physics/stateEquation.ts`，代表档距 Lr=√(ΣL³/ΣL)，
   应力形式 σ − γ²Lr²E/(24σ²) = C，牛顿迭代。
3. **比载**：`src/physics/loads.ts`，GB 50545 口径的自重、环形冰截面冰重、无冰/覆冰风荷载，
   冰密度 900 kg/m³。
4. **连续档串偏摆**：`src/physics/sectionSolver.ts`，先求全段统一水平张力（线长协调二分），
   保留 8% 有界残余不平衡张力，再按两侧纵向/横向力与垂直荷载之比迭代悬垂串偏角，
   偏摆位移回代各档档端坐标。均匀荷载下纵向偏角严格为 0。
5. **净距**：`src/physics/clearance.ts`，逐采样点量对地与跨越物距离，排除塔基 12m 防护区。
6. **舞动**：`src/physics/galloping.ts`，垂直/水平驻波 + 相位差构成椭圆轨迹；
   三维画面与相间距曲线共用同一份逐帧世界坐标，数值逐点一致。

## 三项验收对照

- **弧垂精度**：`tests/physics.test.ts` 中状态方程解与独立三次方程手算、悬链线与抛物线弧垂
  对照误差均 <1%（实测平档偏差约 0.1–0.2%）。
- **性能**：间隔棒全部走 `InstancedMesh`，演示线路 153 个间隔棒、2256 个线缆采样点，
  重冰满几何浏览器实测 60 FPS；单次全线路力学计算约 1.3ms。
- **舞动同源**：`tests/integration.test.ts` 逐帧手工量测与曲线函数值误差 <1e-12；
  浏览器内 HUD 实时距离与曲线表最小值时刻完全吻合。
